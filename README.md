# English Shadowing

미팅 영어 쉐도잉 연습 페이지. 휴대폰과 노트북 브라우저에서 바로 열린다.

**사이트:** https://jeongtai.github.io/english-shadowing/

- 문장을 영어 음성(TTS)으로 듣고, 같은 길이만큼 쉬는 동안 따라 말한다. 반복 횟수와 속도를 고를 수 있다.
- 우리 쪽 문장은 실제로 한 말과 다듬은 문장을 같이 보여주고, 상대 쪽 문장은 그대로 따라 할 표현으로 둔다.
- 빈칸 모드(기본 켜짐)는 문장마다 다음 미팅에서 다시 쓸 표현만 가린다. 먼저 말해보고 문장을 누르거나 재생하면 정답이 보인다.
- 영어 가리기를 켜면 한국어만 보고 먼저 말해본 뒤 확인할 수 있다.
- 녹음 버튼으로 내 발음을 녹음해 원문과 번갈아 들을 수 있다. 녹음은 기기 밖으로 나가지 않는다.
- 공개 페이지라 회사명, 인명, 수치는 가명과 예시 숫자로 바꿨다.

정적 페이지 하나(`index.html`)라 빌드가 필요 없다.
